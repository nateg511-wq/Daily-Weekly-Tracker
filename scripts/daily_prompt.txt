Run today's DAILY cycle exactly as CLAUDE.md's "update cycle" section describes, using the "light" path:

1. Quant refresh: `./.venv/Scripts/python.exe run.py quant` then `./.venv/Scripts/python.exe run.py numbers`.
2. 3. 5. Stage the changed files and commit with a clear message describing what changed, why, and whether it was auto-stamped (or "no material change" if nothing moved). Confirm the commit succeeded (`git log -1` / `git status`) before moving to step 8. A run that ends with anything still uncommitted in the working tree is incomplete, not "awaiting approval" — there is no approval step here.
8. End by printing a short summary: today's date, whether anything moved, the current THE FINAL NUMBER, whether it was auto-stamped or left as draft (and why), and what (if anything) needs the owner's (Alex's) attention.
